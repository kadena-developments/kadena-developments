This is the GitHub page for Kadena Wallet, a desktop application that holds KDA and signs for
accounts on Chainweb. It runs on Windows, macOS and Linux, keeps keys on the machine you installed it
on, and talks to a node you can choose. The three installers below are built from the same source and
tagged together, so a fix on one platform ships on the other two. Every release carries the same three
file names and their checksums, so a build already on your disk can always be identified.

The wallet exists because the network outlived the company that started it. Kadena LLC wound down in
October 2025; the twenty chains kept producing blocks, maintained by a community team, and the accounts
on them never moved. What changed is support. Most of the pages in this account exist because a holder
had a question and there was nobody left to ask, so each one was written from primary sources, dated,
and marked where the evidence ran out. The dates are the point: an answer written while the company was
still trading is wrong now, and each page says which half of that story it describes.

The guides here are organised by the problem you arrived with, not by feature. If your balance looks
wrong, start in the balance and chain cluster. If you are moving from Chainweaver, Koala, eckoWALLET or
Linx, start in the keys cluster, because migration is a derivation question before it is a software
question. If you are trying to work out what is still trading, what was delisted and on what date, start
in the market cluster. Every page is designed to be entered on its own; none assumes you have read
another first. Each one opens with the situation it is written for, then the explanation, then the
questions readers actually ask, so you can stop reading as soon as your own case is answered.

Two habits run through the whole set. The first is verification: every claim about chain state can be
checked against a block explorer or a node, and the pages show you how rather than asking you to trust
them. Where a claim cannot be checked at all, the page says so instead of sounding certain, and the gap
is named rather than smoothed over. The second habit is that your recovery phrase is not a password. No support process, no page here, and
no legitimate tool needs it typed into a chat window, a form or a website.

## Who it is for

- You hold KDA and want a desktop wallet whose keys you control rather than a venue's.
- You are arriving from another wallet and need to know what carries over before you type a phrase.
- You are trying to work out what is still trading, what was delisted, and on what date.

## Common first questions

### Is this the official Kadena wallet?
No. Kadena LLC stopped operating in October 2025 and publishes no wallet; this is an independent desktop wallet written and maintained by its own contributors.

### Does the wallet hold my funds?
No. The chain holds the balance and your recovery phrase holds the authority to move it, so the application signs transactions rather than custodying anything.

### Where do I start if my balance looks wrong?
Start with the zero-balance guide, which separates a missing price quote from a chain the wallet is not displaying in about five minutes.
